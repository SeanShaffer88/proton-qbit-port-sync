# Windows installer preview

```text
┌─────────────────────────────────────────────────────┐
│ Proton qBittorrent Port Sync Setup                   │
├─────────────────────────────────────────────────────┤
│ Before you install                                  │
│                                                     │
│ • Enable port forwarding in Proton VPN               │
│ • Bind qBittorrent to your Proton network interface   │
│ • Exit qBittorrent, including its tray icon           │
│                                                     │
│ Setup installs for your Windows account.             │
│ No administrator rights or script commands needed.   │
│                                                     │
│                       [ Back ] [ Next ] [ Cancel ]   │
└─────────────────────────────────────────────────────┘
```

Flow: prerequisites → ready to install → configuration and startup → finish.
Prerequisite failures appear in the wizard with a specific fix and a retry option.
Windows Installed apps and the Start menu expose the uninstaller.
